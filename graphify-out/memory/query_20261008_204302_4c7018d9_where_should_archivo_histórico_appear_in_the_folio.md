# Q: Where should Archivo histórico appear in the Folio sidebar?

## Answer

User preference: make Archivo histórico the first sidebar option, before Recepción de planillas. It is an independent destination for finding and recovering original historical ZIP files, not a mandatory step in reception. Preserve uploaded ZIPs unchanged and identify them by service, month, and year. Recorded in PRINCIPIOS_DE_PRODUCTO.md under 'Decisión de navegación: Archivo histórico primero'.
